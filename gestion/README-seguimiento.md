# Seguimiento operativo de contactos

Este paquete sirve para ordenar respuestas recibidas desde el formulario operativo de La Esencia.

## Uso recomendado

1. Abrir la planilla de respuestas del Google Form.
2. Agregar las columnas internas de matriz-seguimiento-contactos.csv.
3. Crear filtros.
4. Crear pestañas:
   - Respuestas del formulario
   - Seguimiento operativo
   - Mensajes modelo
5. Revisar semanalmente estados, prioridades y próximos pasos.

## Nota institucional

El formulario expresa intención de contacto o participación ciudadana inicial. No constituye afiliación partidaria formal ni inscripción legal a una organización política.
