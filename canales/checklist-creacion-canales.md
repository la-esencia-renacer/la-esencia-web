# Checklist de creación de canales

## Antes de crear

- Confirmar correo institucional de recuperación.
- Activar verificación en dos pasos.
- Definir quién administra cada canal.
- No usar contraseñas compartidas por mensajes.
- No publicar teléfono personal.

## Instagram

- Crear usuario.
- Completar bio.
- Cargar logo institucional.
- Agregar link a web.
- No publicar hasta revisar primera placa.

## Facebook

- Crear página, no perfil personal.
- Completar nombre y descripción.
- Cargar logo institucional.
- Agregar link a web.
- No activar publicidad.

## LinkedIn

- Crear página institucional.
- Completar descripción sobria.
- Agregar web.
- No vincular publicaciones personales todavía.

## WhatsApp

- Conseguir línea exclusiva.
- Configurar WhatsApp Business.
- Cargar descripción.
- Agregar web y correo.
- No publicar el número en la web hasta validar uso interno.

## Después de crear

- Registrar enlaces públicos.
- Probar acceso.
- Verificar seguridad.
- Preparar primera publicación suave.
- Registrar usuarios y links en documento interno seguro fuera del repositorio público.
